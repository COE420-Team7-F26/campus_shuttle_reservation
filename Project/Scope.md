Exercise 2: Define the Project Scope
Define the initial scope of your software project.


1. Project Objective

Provide a clear statement describing the main purpose of the project and the problem it aims to address.
The main purpose of our project is to create an application that helps students track and reserve seats on campus shuttles. It aims to address the problems of unpredictability as most students are unaware of whether the shuttle would arrive on time (as written in the timetable) and if it would have any seats when it does so, which can result in longer wait times in the hot and humid weather.

2. Target Users

Identify the main users or beneficiaries of the proposed system.
Our system is designed for three main users: students who ride the campus shuttles, drivers that operate those shuttles, and also a transport administrator that manages updating shuttle timetables and account access.

3. In-Scope Features

List the major features and functionalities that will be included in the project.
The functionalities vary depending on the type of users. Students would have the features of seat booking, viewing shuttle timetable, real-time occupancy, seat cancellation, and they will be sent notifications about shuttle delays, any changes in the timetable, and the shuttle’s live location. The shuttle drivers would have the features of reporting status updates (such as delays/ lateness). Their live location will be tracked by the application. Both students and drivers would be able to flag the other as “no-show”. The transport administrator can update the shuttle timetable in the app, and can review no-show reports and either suspend the account or dismiss the report.

4. Out-of-Scope Features

Identify features or functionalities that will not be included in the current version of the project.
Out of scope features include allowing students to import their schedules and class location so that the system automatically reserves shuttles that are close to them around that time, and having a broader driver review system that includes written feedback and star ratings.  

5. Major Deliverables

Identify the main expected deliverables of the project, such as software components, documentation, prototypes, or other project artifacts.
Our deliverables include what is required from us in this course:
- Software requirements document and initial planning document
- Software structural design document
- Software architectural design document
- Software coding and testing document
- Software project management document
